# EV3 Line Follower
## Использованные программы
[Clev3r](https://clev3r.ru/) - среда разработки (IDE) для программирования «умного кирпича» EV3 от LEGO на языке программирования Basic Plus.
Была использована именно эта IDE поскольку работать с блоками мне наскучило, а эта ide предоставляла полноценное программирование даже с некими отголосками ООП, что меня очень заинтересовало
## Краткая история и задание
Этот проект был подготовлен в спешке к олимпиаде за 3 дня
- Олимпиада "Робофест"
- Направление СКЛАДСКИЕ РОБОТЫ
- Сезон 2022/2023
